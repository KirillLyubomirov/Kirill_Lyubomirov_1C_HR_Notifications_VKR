# Открытие результата в учебной 1С

Установленная платформа: 8.3.27.1508, C:\Program Files (x86)\1cv8t\8.3.27.1508\bin\1cv8t.exe.

Для открытия на своём компьютере восстановить Accepted.dt в новой пустой информационной базе по приведённым ниже шагам. Существующая база на другом компьютере для этого не требуется.

## Быстро показать готовый результат

1. Распаковать комплект. В списке баз добавить новую базу без конфигурации в новую пустую папку.
2. Открыть её в Конфигураторе. «Администрирование → Загрузить информационную базу»: выбрать dist/Lubomirov_Kirill_Sergeevich_Accepted.dt. Согласиться на замену содержимого именно этой новой базы.
3. После перезапуска выбрать vkr_Administrator. Пароли в учебной версии не используются.
4. Запустить «1С:Предприятие». Открыть «Управление уведомлениями»: 120 заданий приняты SMTP-сервером, обработка остановлена.
5. Запустить SMTP/RUN_ACCEPTED_MAILPIT.cmd из комплекта выпуска и открыть http://127.0.0.1:8025. Это копия сохранённой базы из 120 писем.
6. Кадровый отчёт: 10–15.08.2026. Отчёты отправок и ошибок: 10.09.2026. Десять ошибок относятся к прежним неуспешным попыткам; текущих неотправленных заданий нет.

## Повторить реальную отправку

В другой новой базе восстановить Lubomirov_Kirill_Sergeevich_Prepared.dt. Она содержит 10 сотрудников, 60 кадровых событий и 120 подготовленных заданий. Отправка выключена. Закрыть ранее запущенное окно Mailpit и запустить SMTP/RUN_NEW_MAILPIT.cmd из комплекта выпуска: он создаёт новую пустую базу писем. В 1С нажать «Включить отправку». Цикл обрабатывает не более пяти заданий, таймер открытого приложения повторяется через 15 секунд. Кнопка «Обработать очередь» запускает очередной цикл вручную. Ожидаемый результат этого чистого повтора: 120 писем и 120 попыток без ошибок. 130 попыток в Accepted возникли из дополнительного отрицательного сценария.

## Пользователи

| Вход | Назначение |
|---|---|
| vkr_Administrator | Настройки и полный сценарий |
| vkr_Kadrovik | Кадровые документы и первые задачи |
| vkr_OperatorUvedomleniy | Очередь и решения оператора |
| vkr_RukovoditelPodrazdeleniya | Руководитель A, отдел кадров |
| vkr_Manager_B | Руководитель другого подразделения |
| vkr_Manager_None | Нет назначения — нет кадровых записей |
| vkr_Auditor | Просмотр истории |

Руководители входят последовательно: учебная платформа допускает один сеанс на базу. Для A и B ожидаются по 6 событий и 12 уведомлений; без назначения — 0.

CF нужен для новой конфигурации без прикладных данных. source нужен для «Конфигурация → Загрузить конфигурацию из файлов». Системную политику PowerShell менять для этого запуска не требуется.
