# Контракт будущего адаптера ЗУП

Это спецификация отдельного этапа интеграции, а не испытанный модуль конкретного релиза ЗУП.

| Вход | Использование | Проверка |
|---|---|---|
| Устойчивый ключ кадрового документа | Связь с единым событием | Повтор использует тот же ключ |
| Вид изменения | Выбор правила | Соответствие поддержанным видам |
| Сотрудник и организация | Контекст сообщения | Однозначное сопоставление ссылок |
| Дата действия | Кадровый период | Отдельна от времени обработки |
| Значения до/после | Снимок и ревизия | Исправление создаёт новую ревизию |
| Отмена проведения | Прекращение ожидания | Подтверждённая история остаётся |

Работы: получить точный релиз и разрешённую тестовую копию ЗУП; сопоставить метаданные шести видов документов; реализовать преобразование; проверить повтор, исправление и отмену; проверить права; только после этого включать интеграцию в утверждения о готовности.
