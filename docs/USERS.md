# Пользователи учебной базы

| Вход | Роль |
|---|---|
| vkr_Administrator | Администрирование и полный просмотр |
| vkr_Kadrovik | Кадровые документы |
| vkr_OperatorUvedomleniy | Очередь и решения по исключениям |
| vkr_RukovoditelPodrazdeleniya | Руководитель подразделения A |
| vkr_Manager_B | Руководитель другого подразделения |
| vkr_Manager_None | Пользователь без назначения подразделения |
| vkr_Auditor | Просмотр истории |

Пароли в поставляемой учебной базе не заданы. Учебная платформа допускает один сеанс на базу; входы для сравнения прав выполняются последовательно. Учебные адреса используют домен example.test.
