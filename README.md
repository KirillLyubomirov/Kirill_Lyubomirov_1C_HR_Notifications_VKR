Кадровые уведомления на платформе 1С
====================================

Выпускная квалификационная работа Любомирова Кирилла Сергеевича.

Инструмент формирует письма по кадровым изменениям, подбирает получателей по
правилам, ведёт очередь и историю попыток. Неизвестный результат передачи
разбирает оператор; решение о повторе сохраняется с основанием.

Версия программы — **0.12.1**.

Испытания проведены на учебной платформе **1С:Предприятие 8.3.27.1508**.

Реализация — самостоятельная учебная конфигурация. Для типовой 1С:ЗУП определён
[интеграционный контракт](docs/ZUP_ADAPTER.md).

Проверенный результат
---------------------

| Показатель                            | Значение |
|---------------------------------------|----------|
| Кадровые события                      | 60       |
| Уведомления, принятые Mailpit         | 120      |
| Попытки с учётом контролируемых сбоев | 130      |
| Решения оператора                     | 10       |
| Завершённые процессы / задачи         | 10 / 50  |
| Прикладные отчёты СКД                 | 5        |

Результаты доступны в [протоколе](docs/TEST_RESULTS.md) и первичных
[JSON-файлах](tests/evidence/cases).

Приём SMTP-сервером не равнозначен доставке во внешний ящик или прочтению.

Запуск
------

1.  Загрузить [комплект запуска выпуска
    v0.12.1-vkr](https://github.com/KirillLyubomirov/Kirill_Lyubomirov_1C_HR_Notifications_VKR/blob/main/releases/Lubomirov_1C_0_12_1_Run.zip).

2.  Создать новую пустую базу на указанной платформе и восстановить
    `dist/Lubomirov_Kirill_Sergeevich_Accepted.dt` через Конфигуратор.

3.  Войти под `vkr_Administrator`. Пароль в учебной базе не задан.

4.  Запустить `SMTP/RUN_ACCEPTED_MAILPIT.cmd` из комплекта выпуска. Открыть
    `http://127.0.0.1:8025`.

Подробный порядок: [QUICK_START](docs/QUICK_START.md). Короткий показ:
[DEMO](docs/DEMO.md).
