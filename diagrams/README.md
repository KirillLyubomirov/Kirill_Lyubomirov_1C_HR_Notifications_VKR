# Схемы конфигурации 0.12.1

В final/source находится редактируемый исходник каждой схемы, в final/svg — векторные изображения, в final/png — версии для вставки в Word.

| Формат | Работа с файлом |
|---|---|
| DOT | Открыть в Graphviz; после изменения экспортировать SVG или PDF |
| SVG | Редактировать в Inkscape или другом векторном редакторе; текст и стрелки являются отдельными элементами |
| DBML | Импортировать logical_model.dbml в dbdiagram.io для работы с логической моделью данных |
| Mermaid | Открыть queue.mmd в редакторе Mermaid; условия переходов приведены в QUEUE_LEGEND.md |

В v13 уточнены восемь схем: дерево направлений, декомпозиция IDEF0, целевая DFD, две диаграммы деятельности, ER-модель, состояния очереди и маршрут контроля. Повторяющиеся хранилища D1, D3 и D4 на DFD обозначают одни и те же данные в операционном и отчётном представлениях. Номера переходов очереди согласованы с таблицей 2.4 ВКР.

Для воспроизводимого экспорта всех схем служит render_diagrams.mjs. Требуются Node.js и пакеты @viz-js/viz, sharp. Команда из этой папки: `node render_diagrams.mjs final`. Генераторы SVG сохранены в build_svg.py и build_er.py. Схемы описывают логическую модель; физическую структуру хранения формирует платформа 1С.

Экономические диаграммы находятся в Excel на листе «Графики». В DOCX и PPTX включены объекты диаграмм со встроенными расчётными книгами.
